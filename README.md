> **一个常驻在你们 QQ 群里的 AI 群友，不是没有感情的打工助理。**

它不抢答、不当复读机、更不说「有什么可以帮您」；大部分时间在默默潜水窥屏，看气氛偶尔冒泡接一句神吐槽。它分得清谁是铁哥们、谁是生人，还偷偷拿小本本记着谁欠了全群一顿奶茶……

**状态由代码死死焊住，模型只负责把状态说成人话。**

---

## 它怎样接住一句话

![工作原理概览](docs/readme/flow-cn.svg)

QQ 事件先进入本地状态与消息路由；本地指令可以直接处理，需要生成回复时才进入配置的模型路径。好感度、称呼和账本由代码维护，模型负责语言表达。

## ✨ 为什么好玩？

### 🎭 1. 像个真人群友，绝不抢戏
* **看气氛插嘴**：绝大多数时候安静潜水。默认 8% 概率接茬；聊到群主时更容易被点着（25%）。
* **看人下菜碟**：越熟的群友说话它越爱搭理（亲密度权重 1.6×），生人说话客客气气（0.7×），夜间（23:00–08:00）主动闭嘴不扰民。
* **知进退**：被群友喊「别损了」立即收敛，绝不仗着毒舌无休止抬杠。

### 💖 2. 8 档社交羁绊与好感度系统
好感度是一个纯整数（-100 到 +100），在本地代码里算分、分级与衰减；生成的回复不会直接改写这些数值：
* `💀 黑名单` $\to$ `❄️ 关系很僵` $\to$ `😐 有点生疏` $\to$ `👀 算得上眼熟`
* `🙂 熟人` $\to$ `😎 好朋友` $\to$ `🍻 铁哥们` $\to$ `💖 本命`

*熟人敢损敢护，生人客气自持。同一句话，对生人是「收到，祝好」，对铁哥们是「又来这套，不过这波我站你」。*

### 🎪 3. 5 种人格模式一键切换
全群公共状态，一句口令随时换皮（只有熟人和群主才能指挥它变身！）：
* 🐱 **猫娘模式**：傲娇小猫，张口闭口小鱼干
* 👮 **风纪委员模式**：严肃抓违规摸鱼分子
* 💼 **发疯模式**：怨气冲天的深夜加班打工人
* 🔮 **江湖算命模式**：神神叨叨的江湖半仙
* 🏎️ **秋名山老司机模式**：豪爽仗义的车搭子老哥

### 🧾 4. 《群史记》与承诺催债本
* **会滚动的群记忆**：每天自动压缩聊天记录，沉淀出幽默风趣的《群史记》简报。注入人物名册与稳定状态，减少陈年旧事变成反复出现的口头禅。
* **Flag 催债小本本**：群友吹牛说「明天请全群喝奶茶」？它自动立项入账，超时后上线温和催债，直到当事人说「结清」。

### 🎲 5. 0-Token 光速本地彩蛋
绝大多数群内娱乐**不调用大模型，走本地响应路径**：
* **赛博决斗**：摇骰子比大小，胜负还会真实计入交情分！
* **本地热梗秒接**：预设圈内黑话，命中直接接梗。
* **随手查档**：查好感、看关系排行榜、查称呼表、翻旧账。

## 🛠️ 藏在水面下的硬核技术

持续运行依靠状态管理、用量限制、输出检查和网关重连；实际可用性与输出行为仍取决于运行环境和服务商：

| 机制 | 做法 | 带来的好处 |
| :--- | :--- | :--- |
| **状态归代码** | 好感度、主副昵称、催债账本全由本地代码持有 | 好感值与当前称呼由本地状态维护；语言表达与状态计算分离 |
| **提示词分层** | Prompt 物理分层（稳定规则 $\to$ 每日记忆 $\to$ 对话历史 $\to$ 本轮动态） | 缓存命中与成本依赖供应商；已有测试记录见设计笔记 |
| **任务分级容灾** | 对话走强档、压缩走弱档、审核走严档，双供应商自动熔断 | 按任务配置模型与 Gemini/智谱回退路径，实际表现取决于服务商可用性 |
| **输入与权限保护** | 本地敏感词表 + 模型审核两道闸，改名节流冷却防批量试名 | 降低恶意输入与批量试名的影响；群主通过私聊暗号认领 |
| **7×24 网关看门狗** | 深度打补丁监控下行心跳，静默假死主动踢线重连 | 检测静默连接并在网络中断后尝试重连 |

## 🚀 5 分钟跑起来

### 1. 克隆与安装依赖

需要 Python 3.10+。项目极其轻量，**无数据库、无繁杂框架**，仅 5 个必要依赖：

```bash
git clone https://github.com/dubianche123/micro-banter-harness.git
cd micro-banter-harness

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. 配置 `.env`

复制配置模板：

```bash
cp .env.example .env
```

打开 `.env` 填入最核心的几项：

```env
# 1. 腾讯 QQ 开放平台凭证
QQ_APP_ID=你的AppID
QQ_APP_SECRET=你的AppSecret

# 2. 它在群里叫什么（触发词，支持多个别名，逗号分隔）
BOT_NAMES=小王,阿王,@小王

# 3. 群主私聊认领暗号（部署前改成只有你知道的一句密语）
OWNER_CLAIM_PHRASE=换成仅你知道的私密口令

# 4. 主 AI 供应商（gemini 或 zhipu）及密钥
AI_PROVIDER=gemini
GEMINI_API_KEY=你的GeminiKey
# ZHIPU_API_KEY=备用的智谱Key（可选）
```

### 3. QQ 开放平台与群内开关（关键两步）

1. **获取全量群消息**：进入你的 QQ 群设置 $\to$ 点击该机器人 $\to$ 将「机器人可获取的群聊消息范围」设为 **「获取群内全部消息」**（这是它能潜水看懂上下文的前提）。
2. **开启私聊（C2C）权限**：开放平台开启单聊权限，用于安全的群主认领与单聊。

### 4. 启动与常驻

```bash
# 直接前台运行
python bot.py

# 或后台挂载（走代理环境）：
HTTP_PROXY=http://127.0.0.1:7890 HTTPS_PROXY=http://127.0.0.1:7890 \
NO_PROXY=bigmodel.cn,open.bigmodel.cn nohup python -u bot.py >> bot.log 2>&1 &
```

> 🍏 **macOS 用户福利**：自带一键安装常驻守护脚本（防休眠 + 挂掉秒起）：
> ```bash
> bash tools/launchd/install.sh
> ```

### 5. 私聊认领群主

机器人启动后，**群主私聊给机器人发送你的暗号**（即 `OWNER_CLAIM_PHRASE`），机器人验证通过后，将永久绑定你的 OpenID 并把好感度锁在顶格，落锁授权。

## 🎮 群里怎么玩？

| 玩法 | 怎么说 | 消耗 Token |
| :--- | :--- | :---: |
| **日常聊天** | `@它` 或者直接喊它的名字（如 `小王 今天吃啥`） | 1 次 |
| **随缘插嘴** | 正常在群里聊天，它会按概率看心情接话 | 1 次 |

| **认领/改名** | 发送 `叫我阿强` / `我是阿强` / `别叫我了` | 0~1 次 |
| **切换人格** | 发送 `猫娘模式` / `发疯模式` / `风纪委员模式` / `算命模式` / `老司机模式` | **0** |

| **关系排行榜**| 发送 `关系榜` / `点名册` / `群友榜` | **0** |

## ⚙️ 常见配置项速览

在 `.env` 中可按需调整机器人的脾气与成本闸门：

* `BANTER_PROBABILITY`：潜水插嘴概率（默认 `0.08` 即 8%）
* `OWNER_MENTION_PROBABILITY`：聊到群主时的插嘴概率（默认 `0.25`）
* `BANTER_COOLDOWN_SECONDS`：插嘴冷却时间（默认 `120` 秒）
* `AI_DAILY_BUDGET`：每天全群 AI 调用上限总预算（默认 `3000` 次，防刷爆钱包）
* `MODE_SWITCH_MIN_AFFINITY`：模式切换门槛（默认熟人 `familiar` 起步，防路人捣乱）
