# 可编辑知识库

这里放维护者确认过的事实，不靠模型从聊天里猜。改文件、保存，下一条相关消息就会用上，**不需要重启，也不需要重新压缩摘要**。

## 文件怎么分

| 文件 | 作用 |
| --- | --- |
| `all.md` | 所有群共享 |
| `<group_id>.md` | 只对某个群生效；同名条目覆盖 `all.md` |

完整群号可以看 `bot.log` 里的 `[群消息]` 行，或 `state.json` 的 `groups` 键。文件名直接用群号，例如 `80B93E...md`。

## 条目怎么写

```markdown
## 阿强请奶茶
关键词：奶茶、请客、答应
阿强答应请全群喝奶茶，具体时间还没定。

## 群规
关键词：规矩、广告、踢人
本群不发广告，也不讨论政治敏感话题。
```

- 每个二级标题（`##`）是一独立条目。
- `关键词：` 一行可写多个词，用逗号、顿号或空格分隔；关键词至少两个字。
- 没有关键词行时，标题本身当关键词。
- 条目正文建议控制在 300 字以内。
- 同一轮最多注入 2 条、总共约 360 字；超出会截断。
- 命中敏感词的条目会被整条跳过。
- HTML 注释 `<!-- ... -->` 不会被解析，可以放心写备注。

## 边界

知识库是**维护者事实**，与摘要冲突时优先；但它只在问题相关时进入本轮动态层，不会每轮全量注入，也不是群友可以随手改的聊天记录。群友不能通过聊天修改这里的文件。
