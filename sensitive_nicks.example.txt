# 敏感词表模板 —— 复制成 sensitive_nicks.txt 再填（那个文件名在 .gitignore 里，不会被提交）
#
# 【用途】命中即拦，两个地方同时生效：
#   1. 起名入口 —— 群友把某个词认领成称呼时直接拒绝
#   2. 摘要出口 —— 模型压缩记忆时若照抄了某个词，就地替换掉，不让它进长期记忆
#
# 【为什么需要它】实测提示词拦不住这类词：给摘要提示词加上「敏感内容不复述」的硬规则后，
# 同一份含词的真实记录，输出里命中的词数一处没少 —— 模型压根不认为那是个敏感词，
# 当普通昵称照抄了。谐音梗本来就是设计来绕过字面识别的，指望模型「认出来」不可靠。
# 所以底线放在这张表上。
#
# 【通用词不用写在这里】职务/尊号（主席、总书记……）、长辈与主子称谓（爸爸、主人、祖宗……）
# 已经内置在 wordfilter.py 的 BUILTIN_WORDS 里。
#
# 【这里放什么】只能靠你自己判断的具体词：群里实际出现过的谐音、暗号、当事人本名等。
# 故意不把任何具体词写进代码或本文件 —— 这类词随语境变化，固化在仓库里既不好维护，
# 也等于把它留在了代码历史里。
#
# 【改动立即生效】按文件修改时间自动重载，加词不用重启机器人。
# 空行和 # 开头的行会被忽略。
#
# 写法示例（把开头的 # 去掉即可生效）：
# 某个谐音词
# 某个暗号
